# 00 — Overview & Arsitektur

## Tentang Project

**Dashboard Ujion v2** adalah platform manajemen agent AI untuk tim marketing & maintenance **Ujion TKA**. Platform ini menggantikan dashboard Node.js read-only yang lama dengan control plane penuh berbasis Next.js + opencode v2.

## Tech Stack

| Komponen | Teknologi |
|---|---|
| Frontend | Next.js 15 (App Router) + TypeScript + Tailwind CSS |
| UI Components | shadcn/ui (copy-paste, bukan dependency) |
| Database | SQLite via better-sqlite3 + Drizzle ORM |
| Auth | PIN-based session (cookie + JWT) |
| Agent Runtime | opencode v2 (`opencode serve` HTTP API) |
| MCP | Model Context Protocol (@modelcontextprotocol/sdk) |
| Deployment | Docker (docker-compose) via Coolify |
| Provider AI | OpenAI, opencode Zen, DeepSeek, Qwen, Mistral, Groq, Together |

## Prinsip Desain

1. **DB sebagai source of truth** — semua data (agent, skill, task, MCP, key, model, log) disimpan di SQLite
2. **File sync** — DB meng-generate `.opencode/agents/*.md`, `.opencode/skills/*/SKILL.md`, `opencode.json`, dan `tugas/*.md` untuk kompatibilitas dengan opencode TUI dan audit trail
3. **opencode sebagai execution engine** — dashboard tidak reinvent agent loop, menggunakan opencode serve HTTP API
4. **TUI tetap berfungsi** — opencode TUI bisa dipakai via SSH untuk sesi interaktif, sharing config yang sama
5. **Keamanan** — PIN auth, API keys encrypted (AES-256-GCM), bind localhost, akses via SSH tunnel atau Coolify proxy

## Catatan Penting

- **PIN default**: `245100` (configurable via env var `DASHBOARD_PIN`)
- **Layout**: sidebar di kiri, konten di kanan, header di atas, footer di bawah
- **Logout**: kembali ke halaman PIN login
- **opencode serve**: jalan di port 4096 (background service)
- **opencode TUI**: tetap bisa dipakai via SSH untuk sesi interaktif
- **File markdown**: `tugas/*.md`, `marketing/*.md`, `maintenance/*.md` tetap di-generate dari DB untuk audit trail
- **Repo ujion-tka-apps**: mounted read-only di container untuk konteks agent
- **Tidak ada rahasia di repo**: API keys di SQLite (encrypted), env vars di `.env.local` (gitignored)
